# WebDAV Downloader

Go-приложение рекурсивно скачивает файлы с WebDAV-сервера, возобновляет работу по сохранённому состоянию и создаёт HTML-отчёт.

## Запуск

Требуется Go 1.22 или новее. Внешних зависимостей нет.

Скопируйте `.env.example` в `.env`, укажите параметры сервера и запустите:

```sh
go run .
```

Или соберите исполняемый файл:

```sh
go build -o yandex_disk_saver .
./yandex_disk_saver
```

Остановка по Ctrl+C или SIGTERM: приложение дожидается активных загрузок и сохраняет состояние.

| Переменная | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `WEBDAV_PROTOCOL` | `http` | `http` или `https` |
| `WEBDAV_HOST` | `localhost` | Имя хоста или IP-адрес, без порта |
| `WEBDAV_PORT` | `80` | Порт WebDAV |
| `WEBDAV_USERNAME` | `user` | Логин |
| `WEBDAV_PASSWORD` | `password` | Пароль |
| `WEBDAV_REMOTE_PATH` | `/` | Начальный удалённый каталог |
| `DESTINATION_DIR` | `./downloads` | Папка для файлов и отчёта |
| `STATE_FILE` | `./state.json` | Файл сохранённого состояния |

Ошибки скачивания обрабатываются отдельной очередью с повторами. При перезапуске незавершённые файлы ставятся в очередь повторно.

Файл `download-report.html` в папке назначения обновляется раз в 30 секунд. В отчёте отображаются папки до второго уровня, общий размер и процент завершённых файлов; папки с ошибками выделяются красным, полностью скачанные — зелёным.
